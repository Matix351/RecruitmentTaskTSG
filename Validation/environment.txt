The standalone AOT player reports native Burst execution TRUE through a BurstDiscard
probe. Benchmark results therefore use native Burst, not the editor fallback.

Rendering is explicitly submitted to an offscreen render target and synchronized with
a one-pixel GPU readback on every frame. A screenshot verifies real geometry rendering.
These timings include an extra GPU completion/readback cost, exclude IMGUI/presentation,
and should not be described as normal windowed FPS or isolated GPU execution times.
Earlier hidden-window trials skipped rendering; those timings were discarded.

The ordinary demo uses a camera and on-screen IMGUI readout. The offscreen path is used
only when both -batchmode and --sdf-benchmark are supplied to the release player.
